# Medical Staff Planning Analysis

## 📋 Project Overview
This project analyzes hospital patient admissions and staff schedules to optimize shift planning and ensure adequate patient coverage. It demonstrates a complete data analysis pipeline using Python, SQL, and machine learning.

## 🎯 Business Problem
Hospitals struggle with staffing efficiency - too few staff leads to burnout and safety issues, too many leads to waste. This project provides data-driven insights for optimal staff planning.

## 🛠️ Skills Demonstrated
- **Python**: Pandas, NumPy, Scikit-learn for EDA and predictive modeling
- **SQL**: PostgreSQL for data storage and querying
- **Data Visualization**: Matplotlib, Seaborn
- **Statistical Analysis**: Descriptive stats, correlation analysis
- **Machine Learning**: Random Forest for admissions forecasting
- **Data Cleaning**: Handling missing values, feature engineering

## 📊 Dataset
Synthetic hospital data generated with Python Faker:
- `patients.csv`: 5,000 patient admissions with timestamps, department, acuity
- `staff_schedule.csv`: 10,000 staff shifts with roles and departments
